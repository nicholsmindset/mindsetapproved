# apps/mobile

Expo (SDK 58) app for iOS and Android: scan a barcode or a label, and get Approved, Caution, Not Approved or Can't verify, with the ingredients behind it.

## How it works
- **Barcode** (Flow A): VisionCamera 5 with the ML Kit barcode output. It checks the phone's cache, then Supabase `products`, then Open Food Facts.
- **Label** (Flow B): photo → ML Kit text recognition on the device → the rules engine. If the barcode wasn't known, the confirmed text is saved to `products`.
- **Verdicts are decided on the phone** by `@mindset/rules-engine` against a cached rules bundle. The app ships with the starter bundle, so the first scan works offline. On each app open it checks `latest_rule_version()` and downloads newer rules in the background.
- **Re-check with AI** sends the photo to the `ocr-fallback` Edge Function, which returns text only. The verdict is still computed on the phone. Photos are never stored.
- **Share:** the result screen renders a verdict card. It can be shared as an image (on a phone) or as a link to `/v/<code>` on the
  admin site (`EXPO_PUBLIC_SHARE_BASE_URL`).
- **Optional account:** email a 6-digit code to sign in, with no passwords or deep links. Rules sync through `user_settings`, and this phone's
  anonymous scans are attached to the account (`claim_install`).
- History, favourites and settings live on the phone (MMKV). Scans are sent anonymously, tied to a random install id, so "Delete my data" can remove them.

| Path | What |
|---|---|
| `src/core/` | Platform-free logic with unit tests: rules sync, product lookup, scan pipeline, OCR text, limits, store |
| `src/platform/` | Device adapters: MMKV, Supabase, ML Kit OCR (`ocr.web.ts` stub), image resize, gunzip, AI client |
| `src/scan/` | `Scanner.tsx` (camera) and `Scanner.web.tsx` (type a barcode or paste a label) |
| `src/app/` | Screens (expo-router): onboarding, Scan, History, Rules, Settings, Result |
| `src/data/starter-bundle.json` | Generated by `pnpm bundle:build`; a test fails if it's stale |

## Run it
```bash
cp .env.example .env.local        # Supabase URL + anon key; leave empty to run fully offline
pnpm test                          # core unit tests
npx expo run:ios                   # or run:android: needs a development build (camera, ML Kit, MMKV are native)
npx expo start --web               # web build for UI work; no camera, enter barcodes or paste label text
```

The camera, ML Kit OCR and barcode scanning only run in a development or production build, not in Expo Go.
